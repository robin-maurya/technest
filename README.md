# TechNest

A modern IT company website built with Next.js, TypeScript, and styled-components.

## Project structure

- `src/app` — App Router pages and routing
- `src/components` — Reusable UI components and layout
- `src/context` — Authentication, theme, and toast providers
- `src/styles` — Global styles and theme definitions
- `src/services` — Mock data for services, testimonials, and activity
- `src/types` — TypeScript interfaces and shared types
- `src/utils` — Utility helpers

## Scripts

- `npm run dev` — Start the development server
- `npm run build` — Build the production app
- `npm run start` — Run the built app
- `npm run lint` — Run ESLint

## Local development

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Notes

The app includes a full auth flow with local storage persistence, dark/light mode, responsive navigation, and reusable styled components.
